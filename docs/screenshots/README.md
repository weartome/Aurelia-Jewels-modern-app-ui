# Device Screenshots Directory

The main `README.md` currently displays the 12-screen **Aurelia Jewels Design Showcase** (`public/assets/aistudio/Aurelia_Jewels_Luxury_App_Showcase_a3e5fbb6.png`) and the 5 bundled studio jewellery photos from `app/src/main/res/drawable/`.

Once you install `Aurelia-Jewels-debug.apk` on a physical Android phone, you can drop real device screenshots into this folder using these recommended filenames:

- `01-home.png` — Home screen with Bridal Hero banner and categories
- `02-luxury-grid.png` — Luxury Jewellery Grid with wishlist hearts
- `03-filter-sheet.png` — Filter & Sort bottom sheet (Category, Material, Price Range)
- `04-product-detail.png` — Product detail page with size selector and CTA
- `05-wishlist-and-bag.png` — Saved wishlist and Shopping Bag with INR breakdown
- `06-checkout-and-orders.png` — 3-step guest checkout and Order Tracking
- `07-design-studio.png` — Admin Design Studio and Bespoke AI Concept Studio

After adding PNG/JPG files here, embed them in `README.md` using standard relative Markdown links such as:

```markdown
![Home Screen](docs/screenshots/01-home.png)
```
